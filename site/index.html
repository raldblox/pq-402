Pay for an API call with a post-quantum signature; get an answer only you can read.

A recorded run of PQ-402 on the QoreChain testnet. A server charges 0.002 fUSD per call. The client pays with its ML-DSA-87 key, once from an escrow deposit and once from a Perennial position. Its question travels sealed to the server's registered ML-KEM-1024 key, and the answer comes back sealed to the payer's. The "model" is a stand-in that answers with a fixed sentence: what is real here is the payment, the settlement and the sealing.

    Reproduce it

    git clone --recurse-submodules https://github.com/raldblox/pq-402.git
cd pq-402
pnpm install && pnpm build && pnpm test

# locally, against an in-memory chain (no keys, no funds)
pnpm example:server          # terminal 1
pnpm example:client          # terminal 2

# on the testnet: fill .env from .env.example, then
pnpm demo
